# ForwardWidgets

本仓库仅对 Forward 模块进行整理，模块经过个人测试，不对使用结果做任何负责，如有任何问题，请自行联系模块作者。
如果需要添加模块，可以申请 PR，经过测试后即可合并。

## 当前维护内容

本仓库在原有 Forward 模块整理的基础上，新增和调整了以下个人维护内容：

- `widgets/imdb_top250_tv.json`：整理 IMDb 电视剧榜单数据，使用 Forward 可处理的 `imdb` 类型条目格式，供其他 widget 作为随机补充片库使用。列表基于 IMDb 高分剧集，并按个人偏好移除了部分条目，额外加入《好汉两个半》《Pluribus》《芭蕾之星》《大明王朝 1566》《走向共和》《红楼梦》《三国演义》《水浒传》《Coupling》等剧集。
- `widgets/network.js`：流媒体平台热门榜单现在只取前 2 个近半年发布的 TMDB 平台热门剧，其余位置从 `imdb_top250_tv.json` 随机补齐，总数保持 12 个。国际平台榜单会过滤恐怖内容，IMDb 随机补位会保证《老友记》《好汉两个半》《The Office》三部中至少出现一部。
- `gengjiawen.fwd`：维护个人订阅入口，便于 Forward 直接读取当前仓库内的 widget 配置。
